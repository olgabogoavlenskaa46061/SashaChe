Сюда можно положить свои кадры со стадионов (mp4, mov) — например, из поездок на матчи.

Если в папке есть видео, бот берёт фон отсюда, а не из стоковых роликов Pexels.
Подойдут вертикальные ролики с телефона по 10–60 секунд: трибуны, поле, болельщики.
Держите файлы небольшими (до 50 МБ каждый), чтобы GitHub их принял.

Кладите только то, что снимали сами: чужие видео и кадры трансляций брать нельзя.
