Сюда можно положить фоновую музыку (mp3, m4a, wav, ogg).

Бот берёт случайный трек и ставит его тихо под голос. Можно разложить треки
по папкам настроения — тогда бот выберет подходящую к сюжету:

  энергично/
  весело/
  драматично/
  вдохновляюще/

Берите только музыку, которую можно использовать бесплатно в роликах:
например, из фонотеки YouTube (YouTube Studio → Фонотека) или Pixabay Music.
Популярные песни не подходят — ролик заблокируют по авторским правам.

Если папка пустая, ролики будут без музыки — её можно добавить прямо
в приложении TikTok / YouTube при публикации.
