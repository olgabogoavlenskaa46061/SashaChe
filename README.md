# ⚽ САША Ч. — бот для шортсов

Бот каждый день готовит шортсы в стиле канала [«САША Ч.»](https://www.youtube.com/@sasha-cheeee/shorts): ироничный голос автора, кадры со стадиона без надписей, в конце — повтор с зумом и замедлением.

## Как это работает

1. **Утром** бот собирает самые популярные футбольные видео за сутки: в X, Instagram и на YouTube — с просмотрами и лайками. Ещё он читает новости (Чемпионат, Sports.ru, Спорт-Экспресс, BBC Sport, SPORTbible), но только чтобы сверять факты.
2. **Claude выбирает 4 момента**: 2 главных, 1 курьёз и 1 интересный. Берёт самые яркие и просматриваемые, без хайлайтов целых матчей и подборок. Упор на «Барселону», «Реал», Месси, Роналду, Ямаля и топ-клубы АПЛ.
3. **На каждый момент пишет текст в стиле Саши**: 45–65 слов, 20–25 секунд, с иронией. Claude видит кадры из видео и подпись автора, а счёт, имена и цифры сверяет с новостями.
4. **Присылает тексты в Telegram**: суть, текст для записи, источники и ссылки «🔥 Смотрят» на видео с этим моментом.
5. **Саша отвечает голосовым** на сообщение с текстом.
6. **Бот собирает ролик**: чистит голос и ставит его на видео этого момента из X (если нашлось) или на стадионные кадры, а в конце делает повтор самого яркого момента с зумом и замедлением. Готовое видео приходит ответом на голосовое. В подписи — название в стиле канала с хештегами, одной строкой для копирования, и описание.

Ответы на сообщение с текстом:

| Ответ | Что сделает бот |
|---|---|
| голосовое | соберёт ролик с голосом Саши |
| слово «бот» | озвучит текст сам нейроголосом |
| свой текст | озвучит этот текст нейроголосом |
| ещё одно голосовое | соберёт новую версию (дубль 2, 3…) |

Голосовые бот проверяет раз в час, так что ролик приходит в течение часа. Сразу можно так: **Actions → Голосовые → ролики → Run workflow**.

Если X, Instagram и YouTube не подключены или не ответили, бот берёт темы из новостей, как раньше, и пишет об этом в сводке. Вернуть темы из новостей насовсем: переменная `TOPIC_SOURCE` = `news`.

**Фон ролика.** Фоном становится само видео этого момента из X или Instagram: горизонтальное — крупно по центру на размытом фоне, вертикальное — на весь экран, его звук тихо идёт под голосом. Повтор в конце бот находит сам — по всплеску звука (рёв трибун, крик комментатора) или по самому активному движению в кадре. Видео с YouTube бот скачать не может (YouTube не пускает серверы), поэтому для таких моментов фон — стоковые кадры Pexels или ваши съёмки из папки `assets/footage`.

⚠️ Видео из X и Instagram — чужие: права на них у авторов, лиг и телеканалов. YouTube распознаёт такие фрагменты, может отдать доход правообладателю или заблокировать ролик, а после трёх страйков удалить канал. Отключить чужие видео в роликах: переменная `USE_CLIPS` = `0`.

| Что | Зачем | Цена |
|---|---|---|
| Ключ Claude API | выбор тем и тексты | ≈ 3–5 $ в месяц |
| Telegram-бот | тексты, голосовые, готовые ролики | бесплатно |
| Ключ Pexels | стадионные кадры на фон | бесплатно |
| Ключ YouTube | самые просматриваемые видео за сутки | бесплатно |
| Токен X | самые залайканные видео за сутки и сами видео для фона | ≈ $0.5 в день |
| Ключ Apify | рилсы Instagram за сутки и сами видео для фона | бесплатно до ~60 рилсов в день |

Без ключа Pexels фон рисуется сам: тёмное футбольное поле. Для стиля Саши ключ очень желателен.

## Шаг 1. Ключ Claude API

1. Зайдите на [platform.claude.com](https://platform.claude.com) и зарегистрируйтесь. Это отдельный кабинет, не подписка Claude Pro.
2. Пополните баланс в разделе **Billing** — нескольких долларов хватит примерно на месяц.
3. Откройте **Settings → API keys** → **Create key**. Скопируйте ключ `sk-ant-...` — он показывается один раз.

## Шаг 2. Telegram-бот и группа

1. В Telegram найдите **@BotFather** (с синей галочкой), нажмите **Запустить** и отправьте `/newbot`.
2. Придумайте боту имя, например `Саша Ч. шортсы`. Затем придумайте адрес латиницей, который заканчивается на `bot`, например `sashache_shorts_bot`. Если адрес занят, добавьте цифры.
3. BotFather пришлёт **токен** — длинную строку вида `123456789:AAH...`. Нажмите на неё, чтобы скопировать, и сохраните в заметках.
4. Создайте в Telegram **группу**, добавьте туда Сашу и бота (найдите его по адресу из п. 2). Админом бота делать не нужно.
5. Напишите в группе `/start@адрес_бота`, например `/start@sashache_shorts_bot`.

Номер чата (`TELEGRAM_CHAT_ID`) искать не нужно: при первом запуске бот сам пришлёт его в группу (шаг 4).

Если голос записываете вы сами, группа не нужна: откройте бота и нажмите **Запустить**.

## Шаг 3. Ключ Pexels

Зайдите на [pexels.com/api](https://www.pexels.com/api/), зарегистрируйтесь и запросите ключ API — он бесплатный.

## Шаг 4. GitHub

Код бота уже лежит в этом репозитории. Осталось добавить ключи и запустить.

1. Откройте **Settings → Secrets and variables → Actions → New repository secret**. В поле **Name** впишите название, в поле **Secret** вставьте значение и нажмите **Add secret**. Так добавьте три секрета:
   - `ANTHROPIC_API_KEY` — ключ Claude (шаг 1)
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather (шаг 2)
   - `PEXELS_API_KEY` — ключ Pexels (шаг 3)
2. **Actions → Тексты на день → Run workflow → Run workflow.** Через 2–3 минуты бот напишет в группу номер чата.
3. Добавьте этот номер четвёртым секретом: `TELEGRAM_CHAT_ID`.
4. Снова **Actions → Тексты на день → Run workflow**, в поле впишите `1`. Через 2–3 минуты в группу придёт текст.
5. Саша отвечает на него голосовым, а вы запускаете **Actions → Голосовые → ролики → Run workflow**. Через несколько минут в группу придёт ролик.

Если запуск закончился красным крестиком, откройте его: причина написана в блоке **Summary**.

Дальше всё идёт само: **тексты — каждый день в 12:23 по Москве (06:23 по Жуан-Песоа)**, голосовые проверяются **каждый час**. Если что-то сломается, в Telegram придёт сообщение с ошибкой, а подробности видны во вкладке **Actions**.

**Про лимиты GitHub.** Для приватного репозитория ежечасная проверка укладывается в бесплатный лимит минут. Если сделать репозиторий публичным, лимита нет вовсе, и проверку можно ставить хоть каждые 15 минут: в `inbox.yml` замените `"41 * * * *"` на `"*/15 * * * *"`. Ключи в Secrets при этом не видны никому.

## Шаг 5. Популярные видео: YouTube, X и Instagram

**YouTube — бесплатно.** Бот тратит около 200 единиц из бесплатных 10 000 в день.
1. Зайдите на [console.cloud.google.com](https://console.cloud.google.com) через Google-аккаунт.
2. Вверху **Select a project → New project**, имя `SashaChe` → **Create**.
3. ☰ → **APIs & Services → Library** → найдите **YouTube Data API v3** → **Enable**.
4. **APIs & Services → Credentials → Create credentials → API key** — скопируйте ключ.
5. Добавьте в GitHub секрет `YOUTUBE_API_KEY`.

**X — платно:** $0.005 за каждый прочитанный пост. Бот читает до 100 постов в день — около $0.5 в день, $15 в месяц. Меньше — переменная `X_MAX_POSTS` (например, `50`).
1. Зайдите на [console.x.com](https://console.x.com) через аккаунт X и примите соглашение.
2. **New App** → любое имя → сразу скопируйте **Bearer Token** (показывается один раз).
3. **Billing → Credits** — привяжите карту и купите пакет кредитов.
4. Добавьте в GitHub секрет `X_BEARER_TOKEN`.

**Instagram — через сервис Apify:** $2.60 за 1000 рилсов, на бесплатном тарифе Apify даёт $5 в месяц — хватает на ~60 рилсов в день (бот берёт до 6 последних рилсов с 10 аккаунтов).
1. Зарегистрируйтесь на [apify.com](https://apify.com) (можно через Google).
2. **Settings → API & Integrations** → скопируйте **Personal API token**.
3. Добавьте в GitHub секрет `APIFY_TOKEN`.

Со следующего запуска в сводке появится строка «📈 Популярное за сутки», а у текстов — ссылки «🔥 Смотрят». Если какая-то площадка не ответит (например, кончились кредиты), бот возьмёт темы с остальных и напишет об ошибке в сводке.

## Настройки

Меняются без правки кода: **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**.

| Переменная | Что меняет | По умолчанию |
|---|---|---|
| `SHORTS_MIX` | сколько тем каждого типа в день | `главное:2,курьёз:1,интересное:1` |
| `VOICE_MODE` | `human` — голос Саши; `tts` — бот сам озвучивает и сразу присылает ролики | `human` |
| `VIDEO_STYLE` | `sasha` — без надписей, с повтором; `news` — с заголовком и крупными субтитрами | `sasha` |
| `SUBTITLES` | `1` — простые субтитры внизу (в стиле `sasha`) | выключены |
| `CLAUDE_MODEL` | модель; дешевле — `claude-haiku-4-5-20251001` | `claude-sonnet-5` |
| `TTS_VOICE` | нейроголос для ответа «бот»; женский — `ru-RU-SvetlanaNeural` | `ru-RU-DmitryNeural` |
| `CHANNEL_NAME` | название канала в текстах | `САША Ч.` |
| `TOPIC_SOURCE` | `viral` — темы из популярных видео; `news` — из новостей | `viral` |
| `USE_CLIPS` | `1` — видео из X и Instagram фоном ролика; `0` — только стоковые кадры | `1` |
| `CLIP_VOLUME` | громкость звука исходного видео под голосом (`0` — без звука) | `0.15` |
| `CLIP_ZOOM` | насколько крупно показывать горизонтальное видео (`1` — целиком по ширине) | `1.35` |
| `X_MAX_POSTS` | сколько постов X читать в день ($0.005 за пост) | `100` |
| `X_ACCOUNTS` | аккаунты X, чьи видео смотреть (через запятую, без @) | 433, brfootball, goal и др. |
| `INSTAGRAM_ACCOUNTS` | аккаунты Instagram, чьи рилсы смотреть | 433, brfootball, goal и др. |

- **Свои кадры** — положите ролики со стадионов в папку `assets/footage`, и бот будет брать фон оттуда.
- **Музыка** — бесплатные треки в папку `assets/music` (в стиле Саши музыки нет, поэтому по умолчанию папка пустая).
- **Время запуска** — строка `cron` в `.github/workflows/daily.yml` (время по UTC; удобно подбирать на [crontab.guru](https://crontab.guru)).
- **Источники новостей** — список `SOURCES` в `config.py`.

## Как публиковать

1. Скачайте ролик из Telegram.
2. Скопируйте строку **«Название для YouTube»** — одно касание по ней в Telegram.
3. Выложите в YouTube Shorts / TikTok / VK Клипы и вставьте название с хештегами и описание.

Перед записью пробегитесь по тексту глазами: бот пишет только по статьям, но имена и цифры лучше проверить за 20 секунд, чем исправлять после. Если хочется сказать по-своему, говорите — бот соберёт ролик из любого голосового.

## Проверка на компьютере (необязательно)

Нужны Python 3.11+ и [ffmpeg](https://ffmpeg.org/download.html).

```bash
pip install -r requirements.txt
cp .env.example .env                 # впишите ключи в .env
python main.py demo                  # демо-ролик без ключей → output/demo/
python main.py demo --voice запись.ogg   # демо с вашей записью голоса
python main.py scripts --dry-run     # тексты на день без отправки → output/<дата>/texts.md
python main.py scripts               # прислать тексты в Telegram
python main.py inbox                 # забрать голосовые и собрать ролики
python main.py auto                  # сделать ролики целиком с нейроголосом
```

## Если что-то не работает

- **Текстов нет в Telegram** — откройте **Actions → Тексты на день** и последний запуск: причина написана в блоке **Summary**.
- **Бот не прислал номер чата** — проверьте, что бот есть в группе, напишите там `/start@адрес_бота` и запустите ещё раз. Сообщения старше суток бот уже не видит.
- **«Токен бота не подходит»** — скопируйте токен из сообщения @BotFather заново, целиком, и обновите секрет `TELEGRAM_BOT_TOKEN` (карандаш рядом с ним).
- **Ответил голосовым, ролика нет** — голосовые проверяются раз в час. Чтобы не ждать, запустите **Голосовые → ролики** вручную. Отвечать нужно именно на сообщение с текстом (свайп влево по нему).
- **«Эта тема уже устарела»** — темы ждут голосовое 3 дня, потом берите свежие.
- **Источник с ошибкой** — сайты иногда меняют адреса лент. Бот продолжит работать с остальными и напишет об этом в сводке.
- **Ошибка про ключ или баланс Claude** — проверьте ключ и баланс на [platform.claude.com](https://platform.claude.com).

## Что внутри

```
main.py                  — запуск: scripts / inbox / auto / demo
config.py                — настройки и список источников
shorts/collector.py      — сбор новостей из RSS за сутки, склейка дублей
shorts/editor.py         — Claude: выбор тем и тексты в стиле Саши
shorts/articles.py       — полные тексты статей для точных фактов
shorts/telegram.py       — сообщения, голосовые, отправка роликов
shorts/inbox.py          — голосовое → ролик
shorts/check_inbox.py    — быстрая проверка новых голосовых для GitHub
shorts/pending.py        — темы, которые ждут голосового
shorts/voice.py          — обработка голоса и нейроголос
shorts/trends.py         — популярные видео за сутки: YouTube, X, Instagram
shorts/footage.py        — фон: видео из X или Instagram, свои кадры, Pexels или нарисованное поле
shorts/render.py         — монтаж ролика и повтор с зумом
shorts/history.py        — память, чтобы не повторять темы
data/                    — история тем и ожидающие голосовые
assets/footage/          — свои кадры со стадионов (необязательно)
assets/fonts/            — шрифт Montserrat (лицензия OFL) для стиля news
.github/workflows/       — ежедневные тексты и ежечасная проверка голосовых
```
