# ⚽ САША Ч. — бот для шортсов

Бот каждый день готовит шортсы в стиле канала [«САША Ч.»](https://www.youtube.com/@sasha-cheeee/shorts): ироничный голос автора, кадры со стадиона без надписей, в конце — повтор с зумом и замедлением.

## Как это работает

1. **Утром** бот собирает футбольные новости за сутки: Чемпионат, Sports.ru, Спорт-Экспресс, BBC Sport, SPORTbible.
2. **Claude выбирает 4 темы**: 2 главные новости, 1 курьёз и 1 интересную историю. Упор на «Барселону», «Реал», Месси, Роналду и топ-клубы АПЛ.
3. **На каждую тему пишет текст в стиле Саши**: 45–65 слов, 20–25 секунд, с иронией. Только факты из статей, своими словами.
4. **Присылает тексты в Telegram**: суть новости, текст для записи и источники.
5. **Саша отвечает голосовым** на сообщение с текстом.
6. **Бот собирает ролик**: чистит голос и ставит его на стадионные кадры, а в конце делает повтор с зумом и замедлением. Готовое видео приходит ответом на голосовое. В подписи — название в стиле канала с хештегами, одной строкой для копирования, и описание.

Ответы на сообщение с текстом:

| Ответ | Что сделает бот |
|---|---|
| голосовое | соберёт ролик с голосом Саши |
| слово «бот» | озвучит текст сам нейроголосом |
| свой текст | озвучит этот текст нейроголосом |
| ещё одно голосовое | соберёт новую версию (дубль 2, 3…) |

Голосовые бот проверяет раз в час, так что ролик приходит в течение часа. Сразу можно так: **Actions → Голосовые → ролики → Run workflow**.

Кадры из трансляций бот не использует: на них права лиг и телеканалов. Фон — бесплатные стоковые видео Pexels или ваши собственные съёмки из папки `assets/footage`.

| Что | Зачем | Цена |

Без ключа Pexels фон рисуется сам: тёмное футбольное поле. Для стиля Саши ключ очень желателен.

## Шаг 1. Ключ Claude API

1. Зайдите на [platform.claude.com](https://platform.claude.com) и зарегистрируйтесь. Это отдельный кабинет, не подписка Claude Pro.
2. Пополните баланс в разделе **Billing** — нескольких долларов хватит примерно на месяц.
3. Откройте **Settings → API keys** → **Create key**. Скопируйте ключ `sk-ant-...` — он показывается один раз.

## Шаг 2. Telegram-бот и чат

1. В Telegram найдите **@BotFather**, отправьте `/newbot`, придумайте имя и адрес бота (должен заканчиваться на `bot`). BotFather пришлёт **токен** вида `123456789:AA...`.
2. Где будут приходить тексты:
   - **Если голос записывает тот же человек, что получает ролики** — просто откройте бота и нажмите **Start**.
   - **Если вы и Саша — разные люди** — создайте группу, добавьте туда Сашу и бота.
3. Узнайте **chat_id**: напишите что-нибудь боту (в группе — `/start@адрес_бота`), затем откройте в браузере (вместо `ТОКЕН` — ваш токен):
   `https://api.telegram.org/botТОКЕН/getUpdates`
   Найдите `"chat":{"id":...` — это и есть chat_id. У групп он отрицательный, например `-1001234567890`.

## Шаг 3. Ключ Pexels

Зайдите на [pexels.com/api](https://www.pexels.com/api/), зарегистрируйтесь и запросите ключ API — он бесплатный.

## Шаг 4. GitHub

Код бота уже лежит в этом репозитории. Осталось два действия:

1. **Settings → Secrets and variables → Actions → New repository secret** — добавьте по одному:
   - `ANTHROPIC_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `PEXELS_API_KEY`
2. Первый запуск: **Actions → Тексты на день → Run workflow**, в поле впишите `1`. Через пару минут в Telegram придёт текст. Ответьте на него голосовым и запустите **Actions → Голосовые → ролики → Run workflow** — через несколько минут придёт ролик.

Дальше всё идёт само: **тексты — каждый день в 12:23 по Москве (06:23 по Жуан-Песоа)**, голосовые проверяются **каждый час**. Если что-то сломается, в Telegram придёт сообщение с ошибкой, а подробности видны во вкладке **Actions**.

**Про лимиты GitHub.** Для приватного репозитория ежечасная проверка укладывается в бесплатный лимит минут. Если сделать репозиторий публичным, лимита нет вовсе, и проверку можно ставить хоть каждые 15 минут: в `inbox.yml` замените `"41 * * * *"` на `"*/15 * * * *"`. Ключи в Secrets при этом не видны никому.

## Настройки

Меняются без правки кода: **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**.

| Переменная | Что меняет | По умолчанию |
|---|---|---|
| `SHORTS_MIX` | сколько тем каждого типа в день | `главное:2,курьёз:1,интересное:1` |
| `VOICE_MODE` | `human` — голос Саши; `tts` — бот сам озвучивает и сразу присылает ролики | `human` |
| `VIDEO_STYLE` | `sasha` — без надписей, с повтором; `news` — с заголовком и крупными субтитрами | `sasha` |
| `SUBTITLES` | `1` — простые субтитры внизу (в стиле `sasha`) | выключены |
| `CLAUDE_MODEL` | модель; дешевле — `claude-haiku-4-5-20251001` | `claude-sonnet-5` |
| `TTS_VOICE` | нейроголос для ответа «бот»; женский — `ru-RU-SvetlanaNeural` | `ru-RU-DmitryNeural` |
| `CHANNEL_NAME` | название канала в текстах | `САША Ч.` |

- **Свои кадры** — положите ролики со стадионов в папку `assets/footage`, и бот будет брать фон оттуда.
- **Музыка** — бесплатные треки в папку `assets/music` (в стиле Саши музыки нет, поэтому по умолчанию папка пустая).
- **Время запуска** — строка `cron` в `.github/workflows/daily.yml` (время по UTC; удобно подбирать на [crontab.guru](https://crontab.guru)).
- **Источники новостей** — список `SOURCES` в `config.py`.

## Как публиковать

1. Скачайте ролик из Telegram.
2. Скопируйте строку **«Название для YouTube»** — одно касание по ней в Telegram.
3. Выложите в YouTube Shorts / TikTok / VK Клипы и вставьте название с хештегами и описание.

Перед записью пробегитесь по тексту глазами: бот пишет только по статьям, но имена и цифры лучше проверить за 20 секунд, чем исправлять после. Если хочется сказать по-своему, говорите — бот соберёт ролик из любого голосового.

## Проверка на компьютере (необязательно)

Нужны Python 3.11+ и [ffmpeg](https://ffmpeg.org/download.html).

```bash
pip install -r requirements.txt
cp .env.example .env                 # впишите ключи в .env
python main.py demo                  # демо-ролик без ключей → output/demo/
python main.py demo --voice запись.ogg   # демо с вашей записью голоса
python main.py scripts --dry-run     # тексты на день без отправки → output/<дата>/texts.md
python main.py scripts               # прислать тексты в Telegram
python main.py inbox                 # забрать голосовые и собрать ролики
python main.py auto                  # сделать ролики целиком с нейроголосом
```

## Если что-то не работает

- **Текстов нет в Telegram** — откройте **Actions → Тексты на день**, последний запуск, и посмотрите, на каком шаге красный крестик.
- **Ответил голосовым, ролика нет** — голосовые проверяются раз в час. Чтобы не ждать, запустите **Голосовые → ролики** вручную. Отвечать нужно именно на сообщение с текстом (свайп влево по нему).
- **«Эта тема уже устарела»** — темы ждут голосовое 3 дня, потом берите свежие.
- **Источник с ошибкой** — сайты иногда меняют адреса лент. Бот продолжит работать с остальными и напишет об этом в сводке.
- **Ошибка про ключ или баланс Claude** — проверьте ключ и баланс на [platform.claude.com](https://platform.claude.com).

## Что внутри

```
main.py                  — запуск: scripts / inbox / auto / demo
config.py                — настройки и список источников
shorts/collector.py      — сбор новостей из RSS за сутки, склейка дублей
shorts/editor.py         — Claude: выбор тем и тексты в стиле Саши
shorts/articles.py       — полные тексты статей для точных фактов
shorts/telegram.py       — сообщения, голосовые, отправка роликов
shorts/inbox.py          — голосовое → ролик
shorts/check_inbox.py    — быстрая проверка новых голосовых для GitHub
shorts/pending.py        — темы, которые ждут голосового
shorts/voice.py          — обработка голоса и нейроголос
shorts/footage.py        — фон: свои кадры, Pexels или нарисованное поле
shorts/render.py         — монтаж ролика и повтор с зумом
shorts/history.py        — память, чтобы не повторять темы
data/                    — история тем и ожидающие голосовые
assets/footage/          — свои кадры со стадионов (необязательно)
assets/fonts/            — шрифт Montserrat (лицензия OFL) для стиля news
.github/workflows/       — ежедневные тексты и ежечасная проверка голосовых
```
